✨ v50 업데이트 안내

• ⚠️ 데이터 유실 문제 해결 (가장 중요): 이전 버전은 접속할 때마다 구글 드라이브의 내용이 이 컴퓨터의 내용을 무조건 덮어써서, 인터넷이 끊긴 상태에서 입력한 자료가 사라질 수 있었습니다. 이제는 어느 쪽이 최신인지 비교한 뒤, 덮어써야 할 상황에서만 양쪽 수정 시각을 보여드리고 확인을 받습니다. 덮어쓰기 직전에는 현재 자료를 백업 파일로 자동 저장합니다.

• 사진 자동 압축: 민원 사진을 첨부하면 자동으로 크기를 줄여 저장합니다. 저장 공간이 가득 차서 저장이 조용히 실패하던 문제도 해결했습니다. 이제 공간이 부족하면 명확히 알려드립니다. ([설정] → 저장 공간 관리)

• 동명이인 오작동 수정: 같은 세대에 이름이 같은 구성원이 있거나 이름이 비어 있으면 엉뚱한 사람이 수정·삭제될 수 있었습니다. 이제 세대DB의 모든 구성원에게 고유 번호를 부여해 정확히 한 명만 처리합니다. (기존 자료는 자동으로 번호가 부여됩니다)

• 시설점검 [수정] 버튼 무반응 해결: 시설점검과 법정점검의 내부 함수 이름이 겹쳐 시설점검 수정이 동작하지 않던 문제를 고쳤습니다.

• 반쪽 백업 제거: 기존 '데이터 내보내기(JSON)'는 헬스장·주차·사물함·세대DB·설정만 저장하고 업무일정·체납·점검·민원·재고·법정점검·자산은 빠뜨렸습니다. 이제 [전체 데이터 백업] 하나로 모든 자료를 저장합니다.

• 보안 정리: 소스에 그대로 적혀 있던 설정 비밀번호를 제거했고, 입주민 성명·메모가 화면을 깨뜨리지 않도록 처리했습니다.

• 데이터삭제주의: PC를 교체하거나 브라우저 초기화시 '데이터 내보내기(JSON)', '데이터 가져오기', '엑셀 파일 다운로드' 기능을 꼭 사용하십시오.

📅 종목별 부과 기준일
기준일까지 등록하면 당월부터, 기준일 다음 날부터 등록하면 익월부터 부과합니다.
예) 기준일 20 → 20일 등록 = 당월 부과 / 21일 등록 = 익월 부과
기준일을 31로 두면 등록일과 관계없이 항상 당월 부과됩니다.
⚠️ 주의: 이 프로그램은 부과액을 저장해두지 않고 조회할 때마다 등록일 기준으로 다시 계산합니다. 따라서 기준일을 바꾸면 이미 지나간 달의 부과 내역까지 함께 바뀝니다. 변경 전 [전체 데이터 백업]을 받아두시고, 과거 고지서와 달라질 수 있다는 점을 감안해주세요.
